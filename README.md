# 🛠️ DigiTools – A Premium Digital Tools Marketplace
A modern, responsive e-commerce platform for discovering and purchasing premium digital products — built as part of a frontend development assignment using React.js and Tailwind CSS.

---

## 🚀 Live Demo
https://digitool-react-project.netlify.app

---

## 🖥️ Tech Stack

| Technology | Purpose |
|---|---|
| **React.js** | Component-based UI |
| **Tailwind CSS** | Utility-first styling |
| **DaisyUI** | Tailwind component library |
| **React-Toastify** | Toast notifications |
| **Vite** | Fast development build tool |
| **JavaScript ES6+** | App logic |

---

## ✨ Features

### 🛒 Cart System
Add products to cart with one click. The navbar badge updates live with the cart count. Remove individual items or clear everything via Proceed to Checkout.

### 🔔 Toast Notifications
Every action — adding, removing, or checking out — triggers a clean toast notification using React-Toastify for smooth user feedback.

### 📱 Fully Responsive
Optimized for mobile, tablet, and desktop. Product grid adapts from 1 to 3 columns and the navbar includes a mobile dropdown menu.
